# FreestyleParser

## Описание
FreestyleParser — это инструмент для автоматического вырезания попыток из видео с серфингом. Скрипт анализирует видео с помощью YOLO, детектирует объекты (люди, лодки, доски) и вырезает попытки с помощью ffmpeg.

## Требования
- Python 3.6+
- OpenCV
- Ultralytics YOLO
- ffmpeg
- Tkinter
- Pillow
- PyYAML

## Интерфейс
# Блок про обработку видео тренировок
Здесь можно выбрать видеозаписи тренировки. Как правило, одна тренировка записана на нескольких больших файлах до 4Гб.
Также можно выбрать зону интереса - область на видео, где выполняются попытки атлетами. 
Только в этой зоне мы пытаемся обнаружить атлета/лодку и понять, что сейчас время попытки.
Также можно выбрать выходную папку, в этой папке будут появляться видео попыток.

# Блок с результатами обработки
Здесь отображается блок с попытками, каждая попытка - миниатюрный скриншот, двойной клик приводит к открыванию видеоплеера с попыткой.
# Блок Атлеты
Тут можно добавлять Атлетов, замеченных на тренировке (пока вручную).
Также миниатюры попыток можно перетаскивать на атлетов и делать привязку попытки к Атлету.
Маппинг атлетов и попыток сохраняется в yaml файле в результирующей папке.
