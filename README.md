# FreestyleParser

## Описание
FreestyleParser — это инструмент для автоматического вырезания попытки атлетов из видеозаписи тренировок по фристайл-каякингу.

Скрипт анализирует видео с помощью YOLO, детектирует объекты (люди, лодки, доски) и вырезает попытки с помощью ffmpeg.

# Основные сценарии
## Отсмотр/анализ тренировки
Записали тренировку, на которой было несколько атлетов, есть флешка с видео, задача — отсмотреть попытки всех атлетов.

Что делать:
   - Открываем FreestyleParser
   - Выбираем файлы для обработки (можно не копировать с флешки на комп). Поддерживаются форматы `.MTS`, `.MP4`, `.AVI`.
   - Выбираем файл в списке — в области интереса появляется скриншот из середины выбранного видео.
     - Кнопка «Область интереса» перебирает кадры с шагом 10% для оценки разных участков видео.
   - На скриншоте рисуем область интереса. Доступны два режима:
     - **Прямоугольник** — растягиваем мышью.
     - **Многоугольник** — кликаем точки, двойной клик завершает фигуру.
     - Если камера двигалась во время записи — потыкайте разные файлы и адаптируйте область интереса.
   - Нажимаем кнопку «Обработать»
   - Ожидаем, через небольшое время должны начать появляться скриншоты попыток в правой части экрана.
     - по скриншотам можно делать двойной клик — откроется QuickTime Player (macOS) или VLC (Windows/Linux) и проиграет попытку.

## Требования
- Python 3.6+
- ffmpeg (с ffprobe)
- OpenCV
- Ultralytics YOLO
- Pillow
- PyYAML

> Tkinter входит в стандартную поставку Python и не требует отдельной установки.

## Готовые сборки
На странице [Releases](https://github.com/aershov/freestyleparser/releases) лежат портативные сборки — Python, модель YOLO и ffmpeg уже внутри, ничего устанавливать не нужно:
- **Windows**: `FreestyleParser.exe` — запустить и работать.
- **Linux** (Ubuntu 22.04+ и другие дистрибутивы с glibc ≥ 2.35): `FreestyleParser-linux-x64` — скачать, сделать исполняемым и запустить:
  ```bash
  chmod +x FreestyleParser-linux-x64
  ./FreestyleParser-linux-x64
  ```

## Установка
1. Создайте виртуальное окружение:
   ```bash
   python3 -m venv env
   source env/bin/activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

# Интерфейс
## Блок «Файлы»
Здесь можно выбрать видеозаписи тренировки. Как правило, одна тренировка записана на нескольких больших файлах до 4 Гб.
При выборе файла в списке в канвасе отображается скриншот из середины видео.

## Блок «Область интереса»
На скриншоте рисуется зона интереса — область на видео, где выполняются попытки атлетами.
Только в этой зоне происходит обнаружение атлета/лодки и определение момента попытки.
Кнопки переключения режима: прямоугольник / многоугольник / очистить.

## Блок «Настройки»
- Выбор выходной папки (открывает / изменяет).
- Кнопка «Параметры обработки ▶» раскрывает дополнительные настройки:
  - Пауза между попытками (сек)
  - Мин. длительность попытки (сек)
  - Запас к началу (сек)
  - Запас к концу (сек)
- Прогресс-бар и кнопки «Обработать» / «Остановить».

## Блок «Попытки» (результаты обработки)
Каждая попытка — миниатюрный скриншот. Двойной клик открывает видеоплеер с попыткой.

### Управление попытками
- **Чекбоксы**: Каждая попытка имеет чекбокс для выбора.
- **Счетчик**: Показывает количество выбранных попыток.
- **Выбрать все / Снять выделение**: Массовое управление чекбоксами.
- **Удаление**: Удаляет выбранные попытки (видео и превью-файлы).
- **Рейтинг**: Кнопки 👍/👎 для оценки попыток (активные кнопки выделены синей рамкой).
- **Фильтры по рейтингу**: Панель фильтрации попыток по оценкам (активные фильтры выделены синей рамкой).
- **Сохранение рейтингов**: Автоматическое сохранение в `ratings.yaml`.

## Блок «Атлеты»
Можно добавлять атлетов, замеченных на тренировке (пока вручную).
Миниатюры попыток можно перетаскивать на атлетов для привязки попытки к атлету.
Доступны фильтры: «Все», «Не разобрано» и по имени атлета.
Маппинг атлетов и попыток сохраняется в `mapping.yaml` в результирующей папке.

## Логи
В нижней части окна отображается лог обработки (автопрокрутка, до 200 строк).

# Файлы данных
Все данные сохраняются в выходной папке:
| Файл | Назначение |
|---|---|
| `processing.yaml` | Конфигурация: ROI, параметры обработки |
| `mapping.yaml` | Привязка попыток к атлетам |
| `ratings.yaml` | Оценки попыток (👍/👎) |
| `NNNN.mp4` | Вырезанные видео попыток |
| `NNNN.jpg` | Превью-скриншоты попыток |
| `canvas.jpg` | Текущий скриншот для канваса |
| `processing.log` | Лог обработки |
