# FreestyleParser

## Описание
FreestyleParser — это инструмент для автоматического вырезания попыток атлетов из видео видеозаписи тренировок. 

Скрипт анализирует видео с помощью YOLO, детектирует объекты (люди, лодки, доски) и вырезает попытки с помощью ffmpeg.

# Основные сценарии
## Отсмотр/анализ тренировки
Записали тренировку, на которой было несколько атлетов, есть флешка с видео, задача - отсмотреть попытки всех атлетов.

Что делать:
   - Открываем FreestyleParser 
   - Выбираем файлы для обработки (можно не копировать с флешки на комп)
     - Под окном выбора файлов показывается скриншот из середины первого выидеофайла.
   - На скриншоте рисуем область интереса (сейчас это прямоугольник)
     - Если камера двигалась во время записи - лучше потыкать разные файлы и посмотреть скриншоты из из разных мест, адаптировать область интереса, чтобы уменьшить вероятность пропуска попыток.
   - Нажимаем кнопку "Обработать"
   - Ожидаем, через небольшое время должны начать появляться скриншоты попыток в правой части экрана.
     - по скриншотам можно делать двойной клик - должен открыться VLC плеер и проиграть попытку

## Интерфейс
# Блок про обработку видео тренировок
Здесь можно выбрать видеозаписи тренировки. Как правило, одна тренировка записана на нескольких больших файлах до 4Гб.
Также можно выбрать зону интереса - область на видео, где выполняются попытки атлетами. 
Только в этой зоне мы пытаемся обнаружить атлета/лодку и понять, что сейчас время попытки.
Также можно выбрать выходную папку, в этой папке будут появляться видео попыток.

# Блок с результатами обработки
Здесь отображается блок с попытками, каждая попытка - миниатюрный скриншот, двойной клик приводит к открыванию видеоплеера с попыткой.
# Блок Атлеты
Тут можно добавлять Атлетов, замеченных на тренировке (пока вручную).
Также миниатюры попыток можно перетаскивать на атлетов и делать привязку попытки к Атлету.
Маппинг атлетов и попыток сохраняется в yaml файле в результирующей папке.
