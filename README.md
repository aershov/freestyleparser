# FreestyleParser

## Описание
FreestyleParser — это инструмент для автоматического вырезания попыток из видео с серфингом. Скрипт анализирует видео с помощью YOLO, детектирует объекты (люди, лодки, доски) и вырезает попытки с помощью ffmpeg.

## Требования
- Python 3.6+
- OpenCV
- Ultralytics YOLO
- ffmpeg

## Установка
1. Установите зависимости:
   ```bash
   pip install opencv-python ultralytics
   ```
2. Установите ffmpeg:
   ```bash
   brew install ffmpeg
   ```

## Использование
Запустите скрипт с помощью команды:
```bash
python process_attempts_simple.py --input <путь_к_видео> --output <путь_к_выходной_директории> --limit <ограничение_в_секундах>
```

### Параметры
- `--input`: директория или файл для обработки (по умолчанию текущая директория).
- `--output`: директория для сохранения попыток (по умолчанию `output`).
- `--limit`: ограничение обработки первыми N секундами видео (по умолчанию обрабатывает всё).

## Логика работы
1. Скрипт ищет все `.MTS` файлы в указанной директории и сортирует их по имени.
2. Для каждого видео файла:
   - Читает каждый третий кадр.
   - Анализирует кадр с помощью YOLO для детекции объектов (люди, лодки, доски).
   - Если в течение 0.4 секунды (0.4 * fps кадров) обнаружены объекты, считает, что атлет в кадре.
   - Если в течение 3 секунд (3 * fps кадров) ничего не обнаружено, считает, что атлет вышел из кадра.
   - Сохраняет таймкоды начала и конца попытки.
3. По таймкодам начала и конца попытки вызывает ffmpeg для вырезания видео.
4. Нумерация попыток сквозная, начиная с `0001.mp4`.

## Пример
```bash
python process_attempts_simple.py --input ./videos --output ./output --limit 120
```
Это обработает первые 120 секунд всех `.MTS` файлов в директории `./videos` и сохранит попытки в директорию `./output`.
